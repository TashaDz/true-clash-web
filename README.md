# True Clash: Unstoppable — playable web build

Прототип №1: шесть непрерывных перетягиваний каната без HP, игрок управляет
картами-спеллами, противник — бот. Играется в браузере, телефон держать
горизонтально: https://tashadz.github.io/true-clash-web/

Вариант **отрядами** (ветка `viz/squads`: юниты идут кучками, правила те же):
https://tashadz.github.io/true-clash-web/squads/

Только билд; исходники — в приватном репозитории TashaDz/true-clash.
Обновляется скриптом `tools/deploy.sh` из основного репозитория.
